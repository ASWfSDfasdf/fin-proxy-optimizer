# w5d_schema.txt —— S-16 五维扫描 CSV 的列语义（独立文件，与数据分开交付）
#
# 适用文件: w5d_scan.csv (= 512 个 shard_XXXX.csv 合并) 及其分片
# 生成脚本: w5d_scan.py          校验脚本: check_w5d.py
# 求解内核: fin3d.py (冻结, md5 40c5732d40534d2d6b454be5151a438c, 341 行)
# 网格表  : grid5d_table.csv     (S-15 产出, 64 组合)
#
# ============================================================================
# 一、文件布局
# ============================================================================
# 每个分片文件自带表头, 65 行 = 1 表头 + 64 数据行。
# 分片号 s ∈ 0..511; 分片 s 的 64 例 = 同一组 (L,h,k) 下全部 64 个 (W,t) 组合,
# 因此 512 片计算量相同, 最贵的 (W=160,t=1) 被均摊到每一片(每片 1 个)。
#
# case_id = block*64 + combo
#     block (= 分片号 s) = (iL*8 + ih)*8 + ik       iL,ih,ik ∈ 0..7
#     combo              = iW*8 + it                iW,it   ∈ 0..7
# 取值表:
#     W_mm : 20, 30, 40, 50, 60, 80, 100, 160      (iW = 0..7)
#     t_mm : 1.0, 1.5, 2.0, 2.5, 3.0, 3.5, 4.0, 5.0 (it = 0..7)
#     L_mm : 30, 40, 50, 60, 70, 80, 90, 100        (iL = 0..7)
#     h    : 10, 20, 40, 60, 80, 100, 150, 200      (ih = 0..7)
#     k    : 50, 100, 150, 200, 250, 300, 350, 400  (ik = 0..7)
# 合计 8*8*8*8*8 = 32,768 例。
#
# 全局常数（不随 case 变化，故不进列）: Tb = 350 K, Tinf = 300 K
#
# ============================================================================
# 二、网格（严格按 grid5d_table.csv, 不许取整简化）
# ============================================================================
# Nx = 80  恒为长度方向 L 的单元数
# Ny = 12  恒为厚度方向 t 的单元数
# Nz = max(32, ceil(3*W/t))    W,t 单位 mm, 即判据 Δz/Δy ≤ 4
# 全部 64 组合中 Nz 的取值范围: 32 .. 480 (Nz=480 仅 W=160,t=1 这一个组合)
#
# ============================================================================
# 三、列语义（21 列；前 16 列为你指定的顺序，后 5 列为审计附加）
# ============================================================================
# 序号 列名          单位/取值          含义
# ---------------------------------------------------------------------------
#  1  W_mm           mm               肋宽（展向尺寸），本次新增的第 5 维
#  2  L_mm           mm               肋长（x 方向，基面在 x=0）
#  3  t_mm           mm               肋厚（y 方向）
#  4  h              W/(m^2·K)        对流换热系数，作用于 y=±t/2 两个大面、
#                                     x=L 尖端面、以及 z=0 与 z=W 两个展向端面
#                                     (fin3d 的 z_bc 默认 "h", 端面不是绝热)
#  5  k              W/(m·K)          导热系数
#  6  Nx             -                长度方向单元数 = 80
#  7  Ny             -                厚度方向单元数 = 12
#  8  Nz             -                展向单元数 = max(32, ceil(3W/t))
#  9  dz_dy          -                (W/Nz)/(t/Ny)，每例都写，供事后审查网格
#                                     全表上限 = 4.0000（判据本身）
# 10  Q_W_per_m      W/m               单位展向宽度的基面导热量 = q_in / W。
#                                     W 翻倍时总热量近似翻倍、此值近似不变；
#                                     它与 W 的微弱单调下降正是侧向端面效应本身，
#                                     不要把它的下降读成散热能力下降。
# 11  tip_T_K        K                 ★ 历史列，见第四节。等于 mean(T[:,:,-1])，
#                                     即 z=W 展向端面的平均温度。**不是尖端温度。**
#                                     保留此列仅为与 v1.0 的 4096 例对齐。
# 12  T_max_K        K                 全域最高温度 = T.max()，恒 ≤ Tb=350
# 13  iters          -                 CG 迭代数；spsolve 行记的是 CG 失败那一刻的
#                                     迭代数（用于诊断 CG 停在哪一层）
# 14  solver         cg|spsolve|none   Q 实际来自哪条求解路径
# 15  t_solve        s                 该例一次求解调用的总墙钟；若发生回落，
#                                     含 CG 失败那次尝试 + spsolve 那次
# 16  note           -                 cg / fallback_spsolve / FAILED
#                                     附加 ";dzdy_gt4" 表示网格判据被破坏（不应出现）
# 17  case_id        -                 0..32767，编码见第一节
# 18  shard          -                 0..511，等于 case_id//64
# 19  tip_L_T_K      K                 ★ 真实尖端温度 = mean(T[-1,:,:])，即 x=L
#                                     面平均。与 tip_T_K 的差值实测 0.32~2.77 K
#                                     （128 例样本），随 W 增大而减小。
# 20  cg_conv        True|False        CG 自身是否收敛（False 表示该例回落过）
# 21  cg_resid       -                 CG 停止时的相对残差 |r|/|b|
#
# ============================================================================
# 四、必须写进 README 的口径警告（不许含糊）
# ============================================================================
# tip_T_K 是「展向端面平均温度」的历史列，不是尖端温度。
#   - 成因: fin3d.assemble 里 c_tip 判定在 i==nx-1（i 是 L 方向），而旧扫描脚本
#     取的是 T[:,:,-1]（z 方向最后一层）。z_bc 默认 "h"，z 端面是对流冷却面，
#     因此该面温度低于真实尖端。
#   - 实测差异（S-16 试跑 128 例）: |tip_L_T_K - tip_T_K| 平均 1.0414 K，
#     最大 2.7730 K（W=20,t=1），最小 0.319 K（W=160,t=5）。
#     同一 t 下随 W 单调递减（端面面积占比 t/W: W=20 时 5%，W=160 时 0.6%）。
#   - 后果: v1.0 的 4096 例 tip_T_K 列、以及 surrogate.npz 的 tip_T 目标，
#     实际都是展向端面温度。W 成为扫描维后该列会随 W 系统性漂移，
#     **不得**当作尖端温度用于 v1.1 拟合。
#   - 正确目标列: tip_L_T_K。
#
# ============================================================================
# 五、求解与容差
# ============================================================================
# 求解器: CG + Jacobi 预条件。
# 容差  : rtol = 1e-10。
#   变更记录（S-16）: 原定 1e-12。作业 73902817 实测 L=100,t=1.0 的算例在
#   1e-12 下 CG 跑满 20000 步、残差停在 9.92e-12 / 1.234e-11，物理上够不到
#   1e-12，于是无条件回落 spsolve（N=30,720 时 10.90 s，N=57,600 时 26.65 s）。
#   新表把 W 做大后 Nz 最大到 480（N=460,800），同样回落外推需 513~2905 s/例，
#   会把 02:00:00 的墙钟顶穿。放宽到 1e-10 后这批例自然收敛。
#   安全性由 tol_check5d.py 单独验证（判据 |ΔQ_II/Q_I| ≤ 1e-8）。
# 回落  : CG 未收敛时用 solver="spsolve"（同装配矩阵的直接解法）重解该例，
#         solver 列记实际路径。
#
# ============================================================================
# 六、不变量（check_w5d.py 校验 A~G）
# ============================================================================
# A 表头逐字符等于 w5d_scan.HEADER
# B 行数 = 64/片；case_id 连续且 = shard*64 + 行序
# C Nx=80, Ny=12, Nz 与 grid5d_table.csv 一致；dz_dy=(W/Nz)/(t/Ny) 且 ≤ 4
# D (W,L,t,h,k) 与 case_id 解码结果一致
# E solver ∈ {cg,spsolve,none}；none 视为 FAIL
# F Q>0；300 < tip_T_K < 350；T_max_K ≤ 350+1e-6
# G 数值字段非空、非 nan/inf
