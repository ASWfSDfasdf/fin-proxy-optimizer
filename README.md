# fin-proxy-optimizer

> 三维单肋稳态导热的数值解 + 参数扫描 + RBF 代理模型。
> 给一块肋片（散热器翅片）的几何与换热条件，**毫秒级**算它的散热能力，
> 再在参数空间里找真正的最优尺寸。

## 一句话

**给 AI agent 用的一句话：**「把这组翅片参数丢给 `predict.py` 出散热能力；
要出报告数字就丢给 `fin3d.py` 真算；要选型就在 4096 个实测点上找 Pareto 前沿。」

## 3. 物理

**控制方程**（肋内三维稳态导热，无内热源）

```
∂²T/∂x² + ∂²T/∂y² + ∂²T/∂z² = 0
```

几何：`x∈[0,L]` 流向、`y∈[0,t]` 厚度、`z∈[0,W]` 展向。

| 位置 | 边界 | 类型 |
|---|---|---|
| x = 0（根部） | T = Tb | 第一类 |
| x = L（端面） | −k ∂T/∂x = h(T − T∞) | 第三类 |
| y = 0, t（上下表面） | ∓k ∂T/∂y = h(T − T∞) | 第三类 |
| z = 0, W（两侧面） | ∓k ∂T/∂z = h(T − T∞) | 第三类 |

**离散**：格心型有限体积，7 点格式。对流面用**串联热阻** `A/(1/h + d/(2k))`，
把边界半格的导热一并计入；根部定温用 `Rx = 2kA/dx`。
不做半格处理会带来一阶热流误差（二维版实测差 20%）。

**热流**：`Q = −k ∫∫ (∂T/∂x)|₀ dy dz`，二阶单侧差分 + 梯形积分。

## 4. 数值与求解

- 网格：G1 = 80×12×32（扫描用）、G2/G3 加密用于收敛验证
- 线性解算：**CG + Jacobi 预条件**（内存 O(n)，可解任意网格）
- 稀疏直接解（`spsolve`）在大纵横比时内存爆炸：G3 需 166 GB，**已排除**。
  纵横比 `Δx/Δy = (L/80)/(t/12) = 0.15·L/t`，**只由 L、t 决定，与 h、k 无关**
- CG 不收敛的算例自动回落 `spsolve`，并在 CSV 的 `solver` 列标注
- `converged` 列**只表示 CG 自身的收敛状态**，与 `solver` 列（cg / spsolve / none）语义分开

## 7. 代理模型（交付物）

### 7.1 三档选型（10 折 CV，seed=20261115）

| 模型 | R²(logQ) | 平均相对误差 | 中位 | **P95** | 最大 |
|---|---|---|---|---|---|
| 幂律 4 项 | 0.9697 | 11.447% | 8.720% | 34.725% | 102.806% |
| 幂律 + 二次交互 9 项 | 0.9829 | 8.385% | 6.322% | 23.850% | 45.583% |
| **RBF thin_plate_spline** | **0.99938** | **1.359%** | **0.671%** | **4.318%** | 10.913% |
| 按 h 分段（≤70 / >70） | 0.9851 | 7.687% | 5.781% | 22.658% | 99.537% |

选 RBF，**对外承诺 P95 ≤ 5%（实测 4.318%）**。
（选型轮用 scipy 默认 degree=1 得 4.373%；交付版重拟合为 degree=0，得 4.318%，两者都 ≤5%。）

### 7.2 交付模型结构

```
Q      = exp( Σᵢ w_i^Q · φ(‖x̂−ĉᵢ‖) + c^Q )        φ(r) = r² ln r，φ(0)=0
tip_T  =      Σᵢ w_i^T · φ(‖x̂−ĉᵢ‖) + c^T
x̂      = (x − min) / (max − min)，四维各自归一化
```

| 项 | 值 |
|---|---|
| 中心点 | 4096（全部实测点），float32 |
| 权重 | 每目标 4096 + 1 常数 = **4097**；两目标共 8194 |
| 多项式 | degree = 0，smoothing = 0 |
| 归一化 | L [30,100]，t [1,5]，h [10,200]，k [50,400] |
| 插值残差 | 7.03e-14（相对无穷范数） |
| 与 scipy 偏差 | max\|ΔlnQ\| = 6.6e-13 |
| tip_T 精度 | 平均 0.080 K，P95 0.369 K，最大 2.446 K |
| 单点耗时 | **368.6 µs** |
| 打包体积 | 78 402 B |

> **degree=0 的严谨表述：** 多项式仅含常数项时，TPS 核矩阵在 n=4096 下不保证非奇异，
> 权重可能不唯一。本算例实测非奇异（残差 7.03e-14），且与 scipy 官方实现的预测偏差仅
> max|ΔlnQ| = 6.6e-13、max|Δtip_T| = 1.35e-11 K。若需**唯一权重**（论文附录要列系数），
> 改 degree=1（多 5 个系数，共 4101），P95 变为 4.373%，仍满足 ≤5% 承诺。
>
> **两个误差不要混：** `predict.py --interp-check` 报的 5.1e-11% 是**训练点**上的插值残差，
> 恒≈ 0；对外能引用的泛化精度只有 10 折 CV 的 **P95 4.318%**。

### 7.3 可解释的定性结论（幂律，**不作为交付模型**）

```
lnQ = −0.859725 + 0.526118 lnL − 0.017760 lnt + 0.535991 lnh + 0.359471 lnk
      − 0.053185 (lnh)² − 0.052018 (lnk)² + 0.107684 (lnh·lnk) + 0.090515 (lnh·lnt)
```

在基准点 (L=50, t=2, h=40, k=200) 的边际弹性：e_L=0.526、e_t=0.316、e_h=0.777、e_k=0.205。
四条都是**单调增 + 增量递减（凹）**，与 `Q ∝ tanh(mL)` 的饱和形态一致：

| 自变量 | 斜率（首 → 末） | 首末比 |
|---|---|---|
| L（mm⁻¹） | 3.3527 → 0.9158 | 3.66× |
| t（mm⁻¹） | 35.28 → 14.32 | 2.46× |
| h（mm⁻¹） | 4.896 → 2.070 | 2.36× |
| k（mm⁻¹） | 0.6184 → 0.0484 | **12.79×** |

k 最早饱和：k 从 200 加到 400 只多 8.2%（189.3 → 204.9 W/m）。

## 8. 两个 Pareto 前沿（全部取自实测点）

### Pareto-1：max Q ↔ min V（26 个非支配点）

knee：**L=60, t=3, h=200, k=400**，Q=19.582 W，V=3600 mm³，Q/V=5.439 W/cm³，tip_T=327.6 K。
两端：Q 从 9.802 W（L=30,t=1）到 29.192 W（L=100,t=5），材料从 600 到 10000 mm³。

### Pareto-2：max Q/V ↔ max Q（24 个非支配点）

knee：**L=70, t=2, h=200, k=400**，Q/V=6.234 W/cm³，Q=17.456 W，V=2800 mm³，tip_T=318.3 K。
两端：Q/V 从 16.336（L=30,t=1）降到 2.919（L=100,t=5）。

**两条前沿全部落在 h=200、k=400。** 原因见 §9.1——h 与 k 不占材料且单调增 Q，
在「Q ↔ 材料」方向上永远取上界，真正的设计自由度只有 L 和 t。

## 9. 边界（回答时必须带上）

### 9.1 为什么 Pareto 前沿必然贴着 h、k 上界

材料体积 `V = L·t·W` 与 h、k **无关**；而 Q 对 h、k 都严格单调增。
于是在任何固定 V 的截面上，`(h,k)` 取上界都被其余点支配——
前沿只能落在 h=200、k=400 的边界上。这不是数值巧合，是结构性的：
**h、k 不是 Pareto 变量，该方向上的"取舍"不存在，只有 L 与 t 在真正权衡。**

### 9.2 外推边界（硬约束）

代理模型仅在 **L∈[30,100] mm、t∈[1,5] mm、h∈[10,200]、k∈[50,400]** 内有效。
越界一律返回「超范围」，**不插值、不裁剪、不外推**：

```python
{"status": "超范围", "reason": "k=500 超出 [50, 400]", "Q_W_per_m": None, "tip_T_K": None}
```

RBF 在凸包外没有物理意义；TPS 核在远处按 r²ln r 发散，外推值会比真值大得离谱。

### 9.3 单肋口径（体积与多肋）

`V = L·t·W` 是**一根肋**的材料体积。多肋阵列：

- 肋间距 s 改变流道与旁通，`h` 不再是单肋自由流的 h
- 直接 `Q_total = N × Q_single` 得到的是「无干扰平行板」的**乐观上界**
- 要报多肋，必须另给 h 的修正（Nu=f(Re,Pr) 或实测），否则不要乘肋数

### 9.4 其它

- `h` 是输入，不预测风速→h（无流固耦合）
- 无辐射、无瞬态、无变物性
- `T_max` 退化为常数（全空间 2.801 K），只能当约束，不能当目标
- 换 `Tb`/`Tinf` 必须重算，不可线性缩放

**p 与 GCI 怎么来的**：三档 Q 由上面两条命令实测，p 与 GCI 由它们按 Richardson 公式算出，可手算复核：

```python
import math
q1, q2, q3 = 228.167600, 228.170561, 228.171306   # G1/G2/G3 实测（W/m）
p   = math.log((q2 - q1) / (q3 - q2), 2)          # 观察阶      -> 1.9908
gci = 1.25 * abs((q3 - q2) / q3) / (2 ** p - 1)   # GCI_fine   -> 1.372e-06 = 1.372e-4%
print(p, gci)
```
